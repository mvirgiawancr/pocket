# Pocket — landing page

**Live: [pocket.virlabs.my.id](https://pocket.virlabs.my.id)**

**Save the change.** A landing page for Pocket, a concept savings app that rounds up every card purchase and tucks the difference away.

Pocket is a concept brand. The waitlist form validates and shows its states, but nothing is sent anywhere.

## What's inside

- Hero with a waitlist form and a stack of product UI cards built in CSS (no device mockups, no stock photos)
- A four-step "how it works" story: spend → round up → pocket → recap
- FAQ built on native `<details>` elements
- Mobile-friendly, keyboard accessible, and respects reduced-motion settings

## Stack

Plain HTML, CSS and a few lines of JavaScript. No build step: open `index.html` or deploy the folder as a static site.

- `tokens.css`: colours, type, spacing and motion tokens
- `styles.css`: layout and components
- `script.js`: scroll reveal, round-up counter, waitlist form states
